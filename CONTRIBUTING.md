# CONTRIBUTING.md - Guía de Contribución

## 🤝 ¿Cómo Contribuir?

Nos encanta recibir contribuciones y nuevas ideas para expandir el mapa de oportunidades de IA.

### 1. Fork el proyecto
Crea tu propia copia del repositorio

### 2. Crea una rama
```bash
git checkout -b feature/nueva-oportunidad
```

### 3. Haz tus cambios
- Agrega nuevas oportunidades en el formato correcto
- Añade información relevante y referencias
- Actualiza la documentación si es necesario
- Asegúrate de que los enlaces funcionan

### 4. Commit
```bash
git commit -m "Add nueva oportunidad de IA"
```

### 5. Push
```bash
git push origin feature/nueva-oportunidad
```

### 6. Pull Request
Abre un Pull Request describiendo la nueva oportunidad

## 📋 Formato de Oportunidades

Asegúrate de que cada oportunidad incluya:
```json
{
  "id": "unique-id",
  "categoria": "Salud",
  "titulo": "Título de la Oportunidad",
  "descripcion": "Descripción detallada",
  "tecnologias": ["ML", "Deep Learning"],
  "impacto": "alto",
  "dificultad": "media",
  "inversion": "media",
  "roi": "alto",
  "timeline": "6-12 meses",
  "recursos": ["enlace a recursos"]
}
```

## 📝 Estándares de Código

- Usa nombres descriptivos
- Comenta código complejo
- Mantén consistencia con el estilo existente
- Prueba tus cambios antes de hacer commit

## 🐛 Reportar Bugs

Si encuentras un problema:
1. Verifica que no esté reportado
2. Abre un Issue con:
   - Descripción clara del problema
   - Pasos para reproducir
   - Comportamiento esperado vs actual

## 💡 Sugerencias de Mejora

Tus ideas son valiosas:
1. Abre un Issue con la etiqueta "enhancement"
2. Describe la mejora propuesta
3. Explica cómo beneficiaría al proyecto
