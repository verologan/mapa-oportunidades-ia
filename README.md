# 🤖 Mapa de Oportunidades en IA

Una plataforma interactiva que explora las oportunidades y aplicaciones de inteligencia artificial en diferentes industrias y sectores.

## 🎯 Características

- **Mapa Visual Interactivo**: Exploración de oportunidades de IA
- **Categorías por Sector**: Tecnología, Salud, Finanzas, Educación, etc.
- **Información Detallada**: Descripción de cada oportunidad
- **Diseño Responsivo**: Funciona en todos los dispositivos
- **Interfaz Intuitiva**: Fácil navegación y exploración
- **Animaciones Suaves**: Experiencia visual atractiva

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Estilos modernos, animaciones y efectos
- **JavaScript (ES6+)**: Lógica interactiva de la aplicación

## 🚀 Cómo Usar

1. **Clonar el repositorio**:
```bash
git clone https://github.com/verologan/mapa-oportunidades-ia.git
cd mapa-oportunidades-ia
```

2. **Abrir en el navegador**:
   ```bash
   # Opción 1: Doble clic en index.html
   # Opción 2: Servidor local
   python -m http.server 8000
   # Abre http://localhost:8000
   ```

3. **Explorar la plataforma**:
   - Navega por las diferentes categorías de IA
   - Haz clic en cada oportunidad para más detalles
   - Filtra por sector o tecnología
   - Descubre nuevas aplicaciones

## 📈 Métricas de Oportunidad

Cada oportunidad incluye:
- **Impacto**: Nivel de transformación (Bajo/Medio/Alto)
- **Dificultad**: Complejidad técnica (Baja/Media/Alta)
- **Inversión**: Requerimiento de recursos
- **ROI**: Retorno esperado
- **Timeline**: Plazo de implementación
